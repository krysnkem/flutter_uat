# Examples

- `login.flow`: a generic scenario. Replace the labels and the credentials with your app's
  (use test accounts only). Run: `flutter_uat -s emulator-5554 -p com.example.app flow login.flow`.
- `sweep_report_sample.md`, `walk_report_sample.md`, `jump_sweep_sample.tsv`: output formats of
  `sweep`, `walk` and the route jump, from a real run on an anonymised app.
